# Threat model

Untrusted CSV files are treated as data: extension, UTF-8 encoding, 10 MiB size, required headers, dates, USD currency, and numeric costs are validated. Credentials never enter fixtures or logs. In Azure, the public web Container App is the only ingress; its same-origin proxy reaches the internal API. MSAL obtains Entra bearer tokens, while the API validates issuer, audience, and operator group claims. The current Terraform creates a Key Vault reference and RBAC design, but Key Vault has a public network path that remains authentication/RBAC protected; it does not set `public_network_access_enabled` or create a Key Vault private endpoint/DNS. This is an unexecuted network-hardening risk, not anonymous access. PostgreSQL credentials and the connection string are represented in Terraform state, so encrypted least-privilege versioned state with access logging is required. Import malware scanning, tenant isolation, budgets/alerts/tags, retention, and recovery/restore validation remain pre-deployment controls.
