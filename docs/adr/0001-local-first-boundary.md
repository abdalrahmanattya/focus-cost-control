# ADR 0001: local-first executable boundary

The local mode uses FastAPI, an in-memory repository, and a daemon import worker so the cost model remains deterministic and runnable without credentials. Compose validates the PostgreSQL repository and migrations. Azure Blob, Service Bus, PostgreSQL, and Container Apps are executable deployment definitions, but no cloud apply is claimed unless captured in release evidence. In cloud mode, the web Container App is the public same-origin edge and uses MSAL to obtain an Entra bearer token; the internal API validates issuer, audience, signature, and operator group before protected operations. Local auth-disabled mode is restricted to development.
